# 配料表分析 v2（2026-11-26）

- 常见添加剂词典提供名称、用途、注意事项；不是穷尽鉴定或中国食品类别/使用限量合规判断。
- 标签 NRV% 原样识别并按实际食用量线性换算，不把缺失值当零，不给糖、添加糖或反式脂肪虚构 NRV。
- 每100g、每100ml、每份必须明确；多列营养表先人工整理为单列。质量和体积不自动互换。
- 参考灯是应用自定的食用量负担提示：已知脂肪/饱和脂肪/钠 NRV（钠缺NRV时用2000mg成人全天控制量）以及明确标注的添加糖/25g目标，占比不超过5%为绿，大于5%且不超过20%为黄，大于20%为红。缺失项目不视为零；这不是官方分级、营养密度评价或食品安全评级。
- 份量预算示例为每天给本食品分配400mg钠或5g明确标注的添加糖（20%全天预算）；不是官方每日产品食用上限、ADI或鼓励吃满的量。总糖不直接当成添加糖。
- 适用一般健康成年人，特殊人群需个体化建议。保存的历史记录按原始文字重新分析，不修改数据库原文。

来源与核对日期在报告“标准与依据”中展示。已阅读中国营养学会《中国居民膳食指南（2022）》、卫健委GB 28050-2025问答及GB 2760-2024发布公告、WHO Healthy diet（2026）和Food additives（2023）、FDA甜味剂科普。中国标准解释为单一主管来源，未把国外法规当作中国合规依据；词典用途只作一般科普，未完成每种添加剂的独立双源和剂量核验，因此不输出有害/超量判定。
